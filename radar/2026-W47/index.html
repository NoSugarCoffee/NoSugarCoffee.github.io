AI 开源雷达 · 第 47 周：技能包长出工具链

2026-11-17 · 0 个新项目 · 15 个新上榜

本周近四成上榜项目围着 agent skill 转：写技能包的、做注册表与跨工具同步的都有，NVIDIA 还出了 SkillEvaluator 做评估。技能正从随手提示词变成可管、可评的工程资产。

  • CLIProxyAPI（router-for-me）— 把 Claude Code、Codex 等 CLI 包成 OpenAI 兼容 API，本周涨七百多星。 ★58.8k · +736/周
  • claude-code-templates（davila7）— Claude Code 组件注册表，一条命令装 skills、agents、hooks，本周涨六百多星。 ★33.9k · +640/周

  • MatrixMedia（hanliang97）— 把视频批量分发到抖音、B 站等八个平台，CLI 和 HTTP API 可供 agent 调用。 ★1.5k
