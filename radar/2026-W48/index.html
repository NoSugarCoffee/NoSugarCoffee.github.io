AI 开源雷达 · 第 48 周：Agent 编排扎堆

2026-11-23 · 0 个新项目 · 13 个新上榜

本周新上榜的项目多围着编码 agent 转：AWS 的 CAO 用隔离 tmux 会话把 Claude Code、Codex 编排成多 agent 并行干活；bend 则要求 AI 改代码时附上数学证明。

↗ 新上榜

  • autoclip（zhouxiaoka）— 贴一个链接把长视频剪成竖版短视频，连字幕、封面、文案一起出；本周涨了两千八星。 ★13.7k · +2.8k/周
  • PyRIT（microsoft）— 微软 AI 红队的开源工具包，用自动扫描和多轮自适应攻击给生成式 AI 系统找漏洞。 ★5k · +174/周
  • CozyClay（HaD0Yun）— 浏览器里的开源 previs：先摆场景、走位和镜头，再连同首帧与提示词喂给 AI 视频模型。 ★2.1k
  • mini-swe-agent（SWE-agent）— 百行代码的编码 agent，仅靠 bash，SWE-bench verified 超 74%，普林斯顿出品。 ★10k
  • appwrite（appwrite）— 开源后端云转向 agent-first：内置 MCP，让 Claude Code 直接操作线上项目。 ★58.6k
  • cli-agent-orchestrator（awslabs）— AWS 出品，把 Claude Code、Codex 等 CLI 编排成多 agent，跑在隔离 tmux 会话里。 ★1.6k
  • WorkDaddy（babygoton）— 用 CDP 增强 WorkBuddy、CodeBuddy：多账号切换、免打扰跑长任务、异常中断自动续接。 ★3.4k
  • bend（bendlang）— 为 AI 写代码设计的语言：规则写进 LAWS 文件，改动须附数学证明，已近两万六星。 ★25.8k
  • itsaplan（croffasia）— 自部署的 Linear 替代品，把 agent 当项目成员派活：内部跑模型，外接 Claude Code 账号。 ★2.5k
  • mastra（mastra-ai）— TypeScript 的 agent 框架，带 workflow 引擎、evals 与可观测性，YC 孵化。 ★29.8k
  • phone-harness（phone-harness）— 让 Claude Code 等直接操作你的真机：滚动、点按、输入、读屏，无需越狱或装 App。 ★5.5k
  • torchtitan（pytorch）— PyTorch 官方的大模型训练平台，一套代码从预训练到 RL，FSDP、TP、PP 可组合叠加。 ★6k
  • edgeever（tianma-if）— 笔记应用，对标 Evernote 与 Obsidian，Cloudflare 免费额度就能自部署，带 MCP。 ★3.5k
