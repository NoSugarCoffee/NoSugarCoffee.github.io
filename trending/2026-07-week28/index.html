calesthio/OpenMontage​

作为首个开源的智能体视频制作系统，该项目标志着AI Agent正从传统的编码任务扩展到复杂的创意领域。其高涨的近期热度（7353）表明，多模态、专业化的Agent应用是当前一个明确的增长方向。

usestrix/strix​

此项目是榜单中综合得分（1147）和近期热度（10338）最高的项目之一，是AI与网络安全结合的典型代表。它的迅速崛起反映了利用AI自动化和增强安全工作流程的迫切需求。

alibaba/page-agent​

由大型科技公司推出的前端GUI智能体，专注于通过自然语言控制网页界面。这是一个非常实用的应用方向，其高得分（636）和热度（3151）表明，无论是个人用户还是企业，对浏览器自动化和图形界面操作的兴趣浓厚。

这是一个用Rust编写的终端智能体多路复用器。选择Rust语言体现了对性能和稳定性的追求，而“多路复用器”这一概念的出现，则暗示着开发者生态正走向成熟——开发者开始同时运行和管理多个Agent，并需要更高效的编排工具。

Methodology​

Data Sources:

  • GitHub Trending pages
  • GitHub API stargazer timestamps

Metrics:

  • Heat_7: Stars gained in last 7 days
  • Heat_30: Stars gained in last 30 days
  • Score: Weighted scoring combining short-term heat and sustained growth
    • Formula: 0.6 × stars_1d + 0.3 × (stars_7d / 7) + 0.1 × (stars_30d / 30)
    • Emphasizes recent activity (60%) while considering sustained trends (40%)

Filtering:

  • Include keywords: %!s(int=30)
  • Exclude keywords: %!s(int=30)
  • Categories: %!s(int=30)

Ranking:

  1. Sort by Heat_30 (descending)
  2. Tie-break by Score (descending)
  3. Select top %!d(string=ai, llm, agent, gpt, rag, langchain, machine-learning, deep-learning, neural, transformer, embedding, vector)

Limitations:

  • Trending data limited to GitHub's trending algorithm
